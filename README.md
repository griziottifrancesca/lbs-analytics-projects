### Conventions

- **Folder names:** `NN-short-project-name`, lowercase, hyphens, two-digit number (`03-customer-churn-model`).
- **File names:** lowercase with underscores, no spaces or `(1)` / `(2)` copies (`churn_analysis.ipynb`).
- **Notebooks:** upload the `.ipynb` when possible, since GitHub renders it with charts. An `.html` export is a fallback.
- **Data:** include the dataset only if it is under 25 MB and allowed to be shared; otherwise link to the source.
- **Group work:** every project README states what I personally did.
